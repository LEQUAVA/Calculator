## 🚀 Getting Started

1. Clone or download the repository
2. Open `index.html` in your web browser
3. Start calculating!

**Keyboard Shortcuts:**
- `0-9` - Number input
- `+`, `-`, `*`, `/` - Operations
- `=` or `Enter` - Calculate result
- `Backspace` - Delete last digit
- `C` or `Escape` - Clear all
