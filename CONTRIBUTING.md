# Contributing

Small fixes and experiments are welcome here.

This is intentionally a plain HTML/CSS/JavaScript project, so you do not need a build tool or framework to work on it.

## Getting started

1. Fork or clone the repository.
2. Open `index.html` in a browser.
3. Make one focused change at a time.
4. Check the calculator with both mouse/touch controls and the keyboard before opening a PR.

## Good first contributions

Useful small changes include:

- tests around calculator edge cases
- accessibility improvements
- small keyboard/interaction fixes
- documentation corrections
- bug fixes that keep the project framework-free

If an issue already exists for the thing you want to change, mention it in your PR.

## PRs

Keep the title simple and say what changed. A short note about how you tested it is enough.

Please avoid unrelated rewrites in the same PR — small diffs are much easier to review.
